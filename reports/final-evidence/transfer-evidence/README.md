# Verify the frozen AeBAD development results

Run `python /path/to/transfer-evidence/verify.py` with Python 3.10 or later from any directory. Only the standard library is required. The verifier checks file hashes, all three seeds and four conditions, macro averaging, seed sample SD, paired endpoint changes, region-population consistency, fixed small-region and detection definitions, gains/losses, and numerical ranking bounds. It does not execute models or recompute metrics from images.

The bundle contains saved metrics and anonymized region identities, with no source images, private absolute paths or weights. Region IDs link the same released-mask component across seeds and endpoints. The three metric seeds share the same development images. Initial maps are diagnostic controls, not competitive baselines. Small and fracture subsets overlap. Region recovery must be interpreted alongside normal pixel false-positive rate.

This applies the method to a new dataset with normal-only refitting. Fitting and calibration use the official training split, and evaluation uses the official test split. The provider defines changed test backgrounds, lighting and viewpoints. Shared folder names do not establish shared capture conditions. This is not zero-shot transfer of learned MVTec flow weights. The data-role receipt verifies separation of paths and saved image hashes among fitting, calibration and evaluation. It does not establish physical-blade or acquisition-session independence.

Data attribution: Zilong Zhang et al., *Industrial Anomaly Detection with Domain Shift: A Real-world Dataset and Masked Multi-scale Reconstruction* (2023), [paper](https://arxiv.org/abs/2304.02216), [official dataset](https://github.com/zhangzilongc/MMR), CC BY 4.0. The 1,479 reserved images are excluded. No statistical-significance, specimen-independence or novel-method claim follows from this bundle. Hashes record consistency with the saved inputs; they are not an independent certification of provenance.
